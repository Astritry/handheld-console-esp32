# Handheld Console - ESP32 

A handheld gaming device I'm building from scratch: hardware + self-written games (Snake, Pong, more planned). Built as a personal project during semester break, combining both sides of my degree at FH Erfurt (Angewandte Informatik / Ingenieurinformatik).


## Hardware
- ESP32 WROOM-32
- 2.8" ILI9341 TFT display (SPI)
- Tactile buttons (6x6mm / 12x12mm)
- 3.7V Li-ion battery + IP5306 charging/boost module
- Passive piezo buzzer
